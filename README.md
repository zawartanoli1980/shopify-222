# T Companies — Shopify Store

A custom Shopify Online Store 2.0 starter theme for a multi-department catalog, plus product-import examples and setup documentation.

## Downloads

- [Complete store kit](artifacts/T-Companies-Store-Kit.zip): theme ZIP, sample CSV, setup guides, and offline design preview.
- [Shopify theme ZIP](artifacts/T-Companies-Shopify-Theme.zip): upload this file in **Shopify Admin → Online Store → Themes → Upload ZIP**.

## Project layout

| Directory | Contents |
| --- | --- |
| `t-companies-theme/` | Editable Liquid theme source, JSON templates, CSS, and JavaScript |
| `t-companies-kit/docs/` | Store setup, sitemap, product-data strategy, and validation notes |
| `t-companies-kit/products/` | Sample CSV: five draft products and seven variant rows |
| `t-companies-kit/preview/` | Offline design preview; open `index.html` in a browser |
| `artifacts/` | Ready-to-download ZIP packages |

The theme includes a responsive homepage, collection grids, product carousel, brand story, configurable customer testimonials, nested navigation, product pages, search/filter markup, cart, contact form, newsletter, and regional selection where configured.

## Before launch

Connect your actual Shopify products, collections, menus, policies, imagery, shipping, taxes, payments, and Shopify Search & Discovery filters. The CSV products are draft/unpublished examples. Preview products and prices are illustrative; preview shopping and form submissions are disabled.

Shopify Theme Check passed with zero errors or warnings. Offline desktop/mobile browser checks passed. The theme has not been deployed to or tested against a live Shopify shop; complete a test order and the [launch checks](t-companies-kit/docs/VALIDATION.md) before publication.
