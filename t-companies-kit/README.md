# T Companies — Shopify Store Kit

Is kit mein Shopify theme ZIP, sample product CSV aur setup guides shamil hain.

## Shopify par upload karne ka tareeqa

1. `T-Companies-Store-Kit.zip` ko apne computer par extract karein.
2. Shopify Admin mein **Online Store → Themes → Import theme / Upload ZIP file** kholein. Admin ke labels version ke mutabiq thore farq ho sakte hain.
3. Sirf andar wali **`t-companies-shopify-theme.zip`** upload karein. Poori kit ko theme ki tarah upload na karein.
4. **Customize** mein apna logo, asli product photos, collections, navigation, shipping/returns text aur brand story set karein.
5. `docs/STORE-SETUP.md` ke mutabiq collections aur filters configure karein. Shopify Search & Discovery install/configure karna zaroori hai agar aap advanced collection filters use karna chahte hain.
6. `products/t-companies-sample-products.csv` sirf example hai. Pehle Shopify se ek product export karke current import headers compare karein. Apne asli products ka chhota pilot import karein.
7. Products, checkout aur mobile experience test karne ke baad hi theme publish karein.

Sample CSV ke products **draft** hain aur published nahin hain. Unko seedha asli inventory samajh kar publish na karein.

## Included files

- `t-companies-shopify-theme.zip` — uploadable Shopify Online Store 2.0 theme.
- `docs/STORE-SETUP.md` — sitemap, theme setup, collection/filter strategy and launch checks.
- `docs/PRODUCT-DATA-DICTIONARY.md` — catalog naming, tagging and metafield blueprint.
- `products/t-companies-sample-products.csv` — five sample products and two additional variant rows.
- `products/shopify-column-reference.md` — column meanings and import cautions.
- `preview/index.html` — browser mein kholne ke liye offline design preview; is mein illustrative sample products hain aur shopping disabled hai.
- `docs/VALIDATION.md` — checks performed and Shopify-side checks still required.

This is a development starter kit. It does not create or connect a Shopify account, import your real 200+ products, configure payments/taxes/shipping, install paid apps, or publish a live store. The included theme must be previewed and validated in your own Shopify store before publication. Example copy and placeholder artwork should be replaced with your own material.
